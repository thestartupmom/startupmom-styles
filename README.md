# startupmom-styles

Stylesheets, fonts and public images only. No page content, no downloads.
Served through jsDelivr, always pinned to a commit SHA (never @main).

- `naptime-academy/` lesson stylesheets for the Naptime Academy course (built by website/naptime-course/build.py)
- `media/` images and video that are already public (e.g. the launch reel, which is on Instagram)
